# Traspaso en issue o PR

```md
- Issue / rama / rol:
- Qué cambió y archivos:
- Contrato, decisión o supuestos nuevos:
- Pruebas ejecutadas y resultados:
- Evidencia (fuente, fecha, unidad, página si aplica):
- Riesgo, bloqueo o pregunta concreta:
- Siguiente acción y persona responsable:
```

Incluye un enlace a la fuente o comando concreto que permita verificar un dato. Evita duplicar el historial del issue.
